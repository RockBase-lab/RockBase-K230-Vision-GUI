# assets/fonts/ — baked bitmap fonts

Fonts already converted to the LVGL binary format the board loads at runtime,
plus the static Latin TTF they came from.

| Pattern | Contents |
| --- | --- |
| `ui_nunito_bold_22.bin` | home-screen tile names (en) |
| `kb_nunito_bold_28.bin` | keyboard labels |
| `ui_cjk_28.bin` | localised tile names, 28 px CJK subset |
| `plate_cjk_30.bin` | plate result text |
| `ocr_cjk_16.bin` | OCR output, 6549 glyphs — the single most expensive font |
| `mono_dejavu_16.bin` | fixed-width readouts |
| `Nunito-Bold-700.ttf` | the static Latin source |

## Rules

1. **Generated by `python tools/gen_font.py`.** The CJK subset comes from
   `tools/ui_cjk_charset.txt`, which `tools/gen_ui_cjk_charset.py` regenerates
   from the zh half of `i18n.NAMES`. Do not hand-craft a `.bin`, and do not edit
   the charset file by hand.
2. **Never use a variable TTF instantiated by `fontTools`.** It loops forever
   inside `stb_truetype` on the first glyph render and wedges the board. Use an
   official static build.
3. **A font that is loaded at boot is listed in `BOOT_FONTS` in
   `shell/boot.py` with its measured load cost.** `ocr_cjk_16.bin` is 7.5 of the
   8 s total; the boot bar weights by milliseconds, not by item count.
4. **Adding a font costs boot time.** Prefer extending an existing subset over
   adding a new size.
5. **Keep the TTF static and small.** The full CJK source font is not committed;
   only the baked subset is. `tools/gen_tz_rows.py` and
   `tools/gen_clock_digits.py` read the TTF from this directory by path, so a
   move must update both.
