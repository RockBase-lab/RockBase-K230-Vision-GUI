# assets/glyphs/ — clock and timer digits

Single-digit bitmaps for the status-bar clock and the timers in the Camera and
Audio apps. Ten digits plus a colon per family.

| Pattern | Contents |
| --- | --- |
| `clock_0.png` … `clock_9.png`, `clock_colon.png` | status-bar clock |
| `timer_0.png` … `timer_9.png`, `timer_colon.png` | in-app timers |

## Rules

1. **Two families stay separate.** The clock is drawn small and dim; the timer is
   large and high-contrast over a live camera preview. Sharing one set makes one
   of the two unreadable.
2. **Generated by `python tools/gen_clock_digits.py`.** Do not edit the PNGs.
3. **Every digit keeps the same advance width**, or the colon jumps as the
   seconds change. The generator pads the glyph box; do not crop it.
4. **Live text is not an option here.** The clock ticks once per second, and
   tiny_ttf re-rasterises on every repaint in FULL render mode, which would stall
   the UI once per second.
