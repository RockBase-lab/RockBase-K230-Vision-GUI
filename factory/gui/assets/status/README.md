# assets/status/ — status-bar icons

The small monochrome bitmaps drawn in the 56 px bar at the top of the screen.

| Pattern | Contents |
| --- | --- |
| `icon_status_home.png` | the Home button on the left |
| `icon_status_wifi*.png` | Wi-Fi: full, 1/2/3 bars, off |
| `icon_status_battery*.png` | battery: frame, 0-3 fill levels |

## Rules

1. **Drawn as bitmaps, never as live text or an LVGL symbol.** The bar repaints
   in `DISP_RENDER_MODE.FULL`; a text glyph would re-rasterise on every repaint.
2. **Generated by `python tools/gen_status_icons.py`.** Do not edit the PNGs.
3. **The battery icon's width is `STATUS_BATT_W` in `shell/theme.py`** and the
   Wi-Fi position depends on it; changing one moves the other.
4. **Sizes are 1x.** The bar is 56 px tall; an icon taller than 40 px will clip.

## Status

Populated: 11 bitmaps (Home, 5 Wi-Fi states, battery frame plus 4 fill levels),
written by `tools/gen_status_icons.py`.
